Adding images to Lungitz

A two-minute guide. Every image is its own item in the Image Sets collection that points back to its entry. You never edit the entry — you make an image and tell it where it belongs.

01 First: which column is the entry in?

This is the only thing people get wrong. The image points back with a different field depending on the column.

Set one of these, never both. Leave the other blank.

02 Then: make the image

  1. CMS → Image Sets → New Image SetOpen the CMS panel, choose the Image Sets collection, click the “New” button.
  2. Name itSomething findable, e.g. Seed Bricks · 06. The slug fills in automatically.
  3. Upload to Image (web)Drag in the processed web-size photo. This is the picture that shows on the site.
  4. Point it at the entryGiveaway → set …Parent giveaway. Hideaway → set Parent. (See step 01.)
  5. Set Order1, 2, 3… — the position this image takes in the entry’s slideshow.
  6. Optional: Caption + Credit (individual)Shown under the image in the lightbox. Nice to have, not required.
  7. Save, then Publish the siteImportant: a new image only appears after a full Publish — saving the item alone won’t show it. Allow a few minutes, then hard-refresh.
✓

That’s it. The thumbnail appears in the entry’s gallery automatically, in the row, in Order. You never touch the entry itself — the image finds its home through the parent field.

04 If it doesn’t show up

›

You set the wrong parent. A Giveaway image needs Parent giveaway; a Hideaway image needs Parent. If you fill the wrong one, the image attaches to nothing (or the wrong column) and stays hidden.

›

You didn’t do a full Publish. Saving the item is not enough — hit the site Publish button, wait a couple of minutes, then hard-refresh (⌘⇧R).

›

No web image yet. The gallery only shows items whose Image (web) is filled. An item with an empty image is skipped.
